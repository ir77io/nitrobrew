# NitroBrew

A macOS menu bar Pomodoro timer themed as nitro cold brew. While you work, a nitro brew fills the glass; on breaks it drains. Pick a pint glass, a nitro can or a pub glass, and the menu bar icon, popover and window all show it.

- Work 25 / 50 and Break 5 / 10 sessions
- A foam head that grows as the glass fills, and a short cascade when a pour starts
- Notification and a soft chime when a pour is done, then a one-click break
- Optional auto-start for breaks and pours
- Session statistics with CSV export
- Resumes correctly after a relaunch (timing is wall-clock based)

Requires macOS 14.6 or later.

## Build and test

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `src/project.yml`.

```bash
cd src && xcodegen generate
xcodebuild test -project src/NitroBrew.xcodeproj -scheme NitroBrew -destination "platform=macOS"
```

For a quick look at a full session, run a debug build with `-NitroBrewDebugSpeed 60` (60x faster clock).

## Releases

Each release is a version tag `vX.Y.Z`. The app shows the version it was built as, in Settings and in the About item, and a release only publishes when the tag matches that version and `CHANGELOG.md` has an entry for it. See `CLAUDE.md` for the steps.
