# NitroBrew

macOS menu bar Pomodoro timer themed as nitro cold brew. A vessel (pint, can or pub glass) fills while you work and drains on breaks, in the menu bar icon, popover and window. Swift only, GPL-3.

Design: `docs/superpowers/specs/2026-11-25-nitrobrew-design.md`. Plan: `docs/superpowers/plans/2026-11-25-nitrobrew.md`.

## Tech Stack
- Swift, SwiftUI + AppKit (`NSStatusItem`, `NSPopover`, `NSHostingController`), UserNotifications
- macOS 14.6+, bundle id `com.ir77io.nitrobrewtimer`, no third-party dependencies
- The Xcode project is generated by XcodeGen from `src/project.yml` (developer tool only)

## Commands
```bash
cd src && xcodegen generate   # run after adding or removing files, or changing project.yml
xcodebuild test -project src/NitroBrew.xcodeproj -scheme NitroBrew -destination "platform=macOS"
```

## Layout
`src/NitroBrew/{App,Timer,Vessels,Views,Resources}`, tests in `src/NitroBrewTests`.

## Releasing
Every update is a new release version, and the app shows it. Bump `MARKETING_VERSION` (and `CURRENT_PROJECT_VERSION`) in `src/project.yml`, run `xcodegen generate`, add a `## X.Y.Z` entry to `CHANGELOG.md`, commit, then tag `vX.Y.Z`. The release workflow fails if the tag does not match the built version or the changelog has no entry.
